# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 4.x / `main` | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

We take the security of Design Atlas and its static assets seriously.

If you discover a security vulnerability (such as a Content Security Policy bypass, cross-site scripting flaw, or credential leak):

1. **Do not open a public issue.**
2. Send an email to the repository owner: `sudhirk926235@gmail.com` with the subject line `[SECURITY] Design Atlas Vulnerability Report`.
3. Provide a clear description of the issue, proof-of-concept steps, and potential impact.

You will receive an acknowledgment within 48 hours. Valid vulnerabilities will be patched promptly and credited in the project release notes.
